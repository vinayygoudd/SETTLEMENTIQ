# SettlementIQ — Operational User Guide

1. **Run Pipeline**: `PYTHONPATH=python/src python3 -m settlementiq.cli`
2. **Run Automated Tests**: `python3 scripts/run_tests.py`
3. **Investigate Exceptions**: Open `excel/SettlementIQ_Reconciliation_Dashboard.xlsx` -> `Exception_Register` tab or `data/sample_outputs/exceptions_register_full.csv`.
